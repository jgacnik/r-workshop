Getting Started with R (JSI-O2 workshop)

A step-by-step setup guide for JSI-O2 workshop participants, held on May 20, 2026
What you'll install: R (the language) → RStudio (the editor) → (package). Follow all three steps in order.
1
Install R
R is the statistical computing engine. Install this first — RStudio won't work without it.
  1. Go to ↗ CRAN Windows
  2. Download the .exe installer
  3. Run it and follow the prompts — defaults are fine
  1. Go to ↗ CRAN macOS
  2. Download the latest .pkg file
  3. Double-click to install
  4. Optionally install ↗ XQuartz (some packages need it)
  1. Visit ↗ CRAN Linux and pick your distro
  2. Debian/Ubuntu: sudo apt-get install r-base
  3. Fedora: sudo yum install R
  4. Make sure you get R 3.2 or newer
2
Install RStudio
RStudio is a friendly editor that makes working with R much easier. You must install R first (Step 1).
  1. Go to ↗ RStudio Downloads
  2. Under Installers, select the Windows version
  3. Double-click the downloaded file to install
  4. Open RStudio — if it launches without errors, you're good!
  1. Go to ↗ RStudio Downloads
  2. Under Installers, select the macOS version
  3. Double-click the .dmg and drag RStudio to Applications
  4. Open RStudio — if it launches without errors, you're good!
  1. Go to ↗ RStudio Downloads
  2. Select the installer matching your distro (e.g. .deb for Ubuntu)
  3. Debian/Ubuntu: sudo dpkg -i rstudio-x.y.z-amd64.deb
  4. Open RStudio to confirm it works
💡 Already have R and RStudio? In RStudio go to Help → Check for updates to make sure you're on a recent version.
3
Install the packages
Open RStudio, click in the Console panel at the bottom-left, and run this command. It will take a few minutes.
install.packages(c("readxl", "tidyverse"))
✅ If you see no error messages after the command finishes, you're all set for the workshop!
